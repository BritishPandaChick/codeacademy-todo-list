# Codecademy To Do List
An functional to-list web page from Codecademy jQuery course.

## Tech Stack
- HTML
- CSS
- JavaScript
- jQuery

## Instructions
1. Clone or download zip file. 
2. Open index.html file in your browser.
3. You will see a headline and a field to input items beside an add button. Type a item in the input field then press add. The page will add this item to the to list in red. When the item is completed, click on the item and it will be removed from the list.
